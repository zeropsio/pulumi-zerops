# Security Policy

## Supported versions

Security fixes are provided for the latest 0.x release. Upgrade to that release before requesting support for an older version.

## Reporting a vulnerability

Report vulnerabilities privately using GitHub's **Report a vulnerability** feature for [zeropsio/pulumi-zerops](https://github.com/zeropsio/pulumi-zerops/security/advisories/new).

Do not open public issues for vulnerabilities. Include the affected provider version, a description of the impact, and minimal reproduction steps. Remove tokens, credentials, state files, and other sensitive data from your report attachments.
